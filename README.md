### 📊 Customer Churn Prediction using Machine Learning

##### 📌 Project Overview

Customer churn is a major challenge for businesses. This project builds a Machine Learning model to predict whether a customer will leave (churn) or stay with the company.

The model uses Random Forest Classifier to analyze customer data and predict churn with high accuracy.

#### 🎯 Objective

Predict customer churn using historical customer data

Identify important factors influencing churn

Help businesses improve customer retention strategies

#### 🗂 Dataset

The dataset contains customer information such as:

Demographics

Account details

Service usage

Contract type

Monthly charges

Tenure

Churn (Target variable)

Target Variable:

Churn → 0 = No, 1 = Yes
